## 构建与启动

```bat
cd server
build.bat
set "XZJ_BACKEND=java"
start.bat
```

- Java 服务端自带 `jdk8`。以上命令显式选择 Java，日常启动入口默认使用 Go。
- 端口：
  - 账号服 HTTPS：`9443`
  - 游戏服 TCP：`17666`
  - 战斗服 TCP：`17667`
- 如果客户端在真机/其它电脑上，需要放行 17666、17667 端口。

## 可调参数

`server/data/config/server.json`：

```json
{
  "cultivationSpeed": 1.0,      // 修炼速度倍率；觉得慢就改 3.0 / 5.0
  "publicIp": "10.0.2.2",       // 下发给客户端的游戏服/战斗服地址
  "offlineCapHours": 12,        // 离线收益上限
  "battlePort": 17667,          // 战斗服端口
  "battleDurationSeconds": 600, // 单场战斗时长
  "monsterCount": 6,            // 每场怪物数量
  "monsterDifficulty": 0.85,    // 怪物整体强度；越低越简单
  "dropMultiplier": 1.0         // 灵石掉落倍率
}
```

`server/data/config/monsters.json` 控制普通/精英/领主的血量、护甲、攻击和波次。
如果还觉得难，把 `monsterDifficulty` 改成 `0.7`，或把 `tiers` 里的 `blood` / `attack` 再调低。

# 补充修复：怪物数值 / 新手引导 / 主线任务

## 5. 怪物数值重做（练气期可正常战斗）

之前编译进 `out/` 的 `DungeonManager` 是旧公式：怪物精血按神识 2/5/10 倍、攻击按神识 0.14 倍，
每一波固定刷 8 只且必带领主，练气期很容易“打不动 / 被围死”。

现在改为数据驱动 `MonsterBalance`：

- 数值基准与客户端一致：
  - 玩家有效伤害 ≈ 神识 × 0.96（青锋剑）
  - 怪物有效生命 = 体魄护甲 + 精血 × 2
- 目标体感：
  - 普通怪 3 下左右
  - 精英怪 5 下左右
  - 领主 10 下左右
  - 一整波怪站着不动约 40~70 秒才会被打死
- 刷怪波次：
  - 外围：5 普通 + 1 精英（无领主）
  - 深处：4 普通 + 1 精英 + 1 领主
  - 兽王巢：1 普通 + 2 精英 + 2 领主
  - 其它副本：4 普通 + 1 精英
- 掉落：普通约 15+3×等级 灵石，精英/领主更高。

配置文件：`server/data/config/monsters.json`（改完重启服务端）。
整体难度还可在 `server/data/config/server.json` 的 `monsterDifficulty` 调整（0.7 简单 / 1.0 标准 / 1.3 困难）。

## 10. 战斗与装备强化

### 10.1 战斗技能
角色现在有 **9 个战斗技能，3 组 × 3 个**，进战斗后点右下角切换技能组：

| 组 | 技能 | 类型 |
|---|---|---|
| 第一组 | 御剑术 / 烈火咒 / 青锋剑 | 单体 / 持续伤害 / 法器 |
| 第二组 | 焚天诀 / 金刚护体 / 聚灵诀 | 范围持续 / 护盾 / 伤害增益 |
| 第三组 | 玄龟诀 / 寒冰咒 / 定身符 | 防御增益 / 减速 / 定身 |

- 技能有独立冷却、施法时间、五行和伤害倍率
- 技能栏配置走 `1009003 SetSkill` / `1009004 RemoveSkill`
- 技能界面 `1009007` 会返回 9 个可配置技能

### 10.2 怪物技能与战斗节奏
- 普通怪：普杀 + 噬咬
- 精英怪：普杀 + 妖术 + 噬咬 + 束缚
- 领主：普杀 + 妖术 + 噬咬 + 冲锋 + 厚皮 + 震慑
- 怪物会远程、持续伤害、减速、控制、加防，不再只会贴脸普攻
- 击杀怪物会获得修为：普通 2%、精英 6%、领主 15% 当前等级修为
- 清完一波额外给灵石和一颗妖丹

### 10.3 战斗掉落与拾取
- 普通怪：45% 材料 / 10% 丹药 / 3.5% 装备
- 精英怪：85% 材料 / 25% 丹药 / 16% 装备
- 领主：100% 材料 / 55% 丹药 / 55% 装备，并额外再掉一件
- 掉落先进入角色 `BattleLoot`，客户端拾取 `1004026` 后才真正进纳戒
- `PickUpGoods` 已支持 `loot_` 前缀物品，拾取后返回新的背包 GoodsId

### 10.4 装备
- 新手礼包现在有：青锋剑（武器）、青布道袍（衣服）、玄铁护心镜（衣服）、青布靴（鞋）
- 装备界面会按等阶显示多件衣服/鞋子，不再是只有一件
- 新增 `1009002 UndressEquipment` 卸下装备
- 套装效果：
  - 衣服 + 鞋：防御 +15%
  - 武器 + 衣服 + 鞋：攻击 +10%
- 装备属性会进入战斗：武器加技能伤害，防具加体魄护甲
- 怪物掉落会出武器/衣服/鞋子，按等级段给 1~16 品阶

### 10.5 可调参数
- `data/config/monsters.json`：怪物精血/护甲/攻击、刷怪组合
