# 修真界 UI 分模块替换清单

以当前 Unity 工程为基线，拆成 **12 个业务组 + 1 个公共与合并组**。每个预制体、待核窗口或设计项只分给一个组。

当前客户端位于同级恢复工程，工程目录没有 Git 元数据。服务端 worktree 不包含这些客户端文件。 [UnityProject](../../../../xiuzhenjie-unity-recovery/UnityProject)

**范围**　234 个窗口预制体、176 个组件预制体（含 48 个战斗 HUD／飘字组件）、5 个代码生成的界面及状态。另列 11 个只有注册键的窗口、3 个旧调用、4 个设计提案。场景、地图地块及角色或技能特效归对应模块维护，按场景入口注明。
