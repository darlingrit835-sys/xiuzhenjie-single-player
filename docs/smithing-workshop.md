# 炼器工坊与装备图录

主城底栏点「装备」，打开「炼器图录」，可按主手、衣甲、护身或足部选图。每张图列出穿戴部位、难度、建议师阶、工序、每件用料，以及成品的攻防、材纹和五行共鸣。「领用样品」可按角色等级免费领取一件认主样品。黄中、黄上、玄下、玄中样品分别在 1、11、21、31 级开放。自行备料铸造可以提前取得。「临图首炼」适合练手或想留下自己模具的角色。「依图铸造」直接用协会模具生产。

| 形制 | 可领样品及对应器图 |
| --- | --- |
| 剑 | 听雪剑、裂缺剑、飞霜剑、流辉剑 |
| 刀 | 归潮刀、破岩刀、赤霄刀 |
| 枪 | 青霜枪、金翎枪、镇泽枪、惊雷枪 |
| 杖 | 松影杖、白芷杖、春山杖、栖霞杖 |
| 弓 | 弦月弓、逐影弓、寒芦弓 |
| 衣甲 | 云纹法衣，云纹木 2 份、寒露液 1 份，袖口贯气、衣襟织纹、内衬护体 |
| 护身 | 寒光护心镜，寒纹铁 2 份、寒露液 1 份，镜面聚光、镜心刻印、镜缘固胎 |
| 足部 | 踏风灵靴，妖兽皮 2 份、云纹木 1 份，靴尖引风、靴面系纹、靴底固形 |

图录按部位挑选器图、同时列出材料的做法参考了《暗黑破坏神 III》的铁匠配方目录。[铁匠配方](https://us.diablo3.blizzard.com/zh-tw/artisan/blacksmith/recipe/)

武器器胚侧重攻击，衣、靴、护心镜器胚侧重防御。成品保留实际攻防和材纹，穿戴多件时词条相加。同五行术法取已穿装备中最高的器印共鸣。

可以先试用听雪剑。寒纹铁 2 份和寒露液 1 份均来自工坊入门材料。领剑后回到「护身行装」穿戴，再到「斗法配置」装上水行的玄冰甲，施放时能看到同水行器印与护盾一起显现。要另铸一把，可从图录点「依图铸造」，也可自己上砧决定新模的攻防取向与品阶上限。[协会器图和固定样兵](../server-go/smithing_patterns.go) · [材料和属性配置](../server/data/config/cultivation_affinities.json)

## 塑形、留模与浇铸

首制依次经过「器胚 → 配料 → 选火 → 塑形 → 炉析」。临图会预填器胚、目标品阶、原方和器名。可以换料、换火，在原图的攻防取向上调整落锤。另选器胚或目标品阶会转为自拟。炉析列出这一次实投的成功机会、败炉每份材料的返还概率、成色和经验，并分项解释增减。改配方或火候后会重新估炉，再确认开炉。

在力道尺的青区落锤才算合拍，前端偏攻、根部偏防。中段保留器图原有的攻防取向。临图时不同难度有各自的火候节奏：以力度 0～9 计，听雪剑的四锤瞄准 3、7、4、6；惊雷枪则是 1、8、1、8。青区会逐锤显示。四锤定形后能反复重塑，再查看模质与实际成品品阶。

| 四锤命中青区 | 模质 | 可留模品阶 | 同行术法共鸣 |
| --- | --- | --- | --- |
| 0 次 | 粗模 | 目标降两档，最低黄阶下品 | 3% |
| 1–2 次 | 良模 | 目标降一档，最低黄阶下品 | 6% |
| 3–4 次 | 精模 | 达到所选目标 | 9% |

首炼成功，纳戒收到一件成品，模架同时留存角色自制模具。首炼失败按现有炉火规则返材，塑形结果可继续使用。首炼器图继承器胚与实投材料的阴阳、五行、气性，并在原有品阶词条外继承材纹。每种材料选取自身最强固有词条，按每件中的材料份额加权。云纹木转移生命上限，寒露液转移增益时长。穿戴后，同五行术法引动器印，攻击与护盾增加威力，增益术延长持续时间。

在「我的模具」选模、配料、选火，选择件数后验料（见习上限 20，每品加 5，九品 65）。第一件按原方足额投料，续件按师阶、器图难度、炉火的驾驭程度及该火与每种材料的五行关系分别节省整份材料。验料单列明原需、实扣、节省、缺料和扣料后格数。换火只改变这炉用量。同模同料复现同一模板，每件有独立物品编号。换用低档材料可能降低成品品阶，模具决定其上限。每满 10 件给本品一堂标准手作经验的 10%，最多按六个十件档计算；过时器图再按师阶差降到 20%–100%。首炼消耗 2＋器图难度＋目标品序的一半（进一）点精力。批铸精力为 2＋器图难度＋件数×（4＋成品品序）÷10（进一）。黄下至天上依次计 1–12 档。每件单独占一格，升级前纳戒有 100 格。估值按攻防、品阶、材纹与模质计算；实际回收最多为实投材料折价的 55%–88%。免费入门材料无购价，认主样品禁止回收。

## 器图为什么分五难

器图难度综合器形、专属纹路、目标品阶、原方用料种数与材料之间的五行相克。两份同种材料仍是一味。临图换料会按实投重新评级，改火或提升师阶则改变驾驭这份难度的效果。自制留模会保存首炼时的难度，早期存档的模具按原有器胚、品阶和原方补算。

| 难度 | 建议炼器师 | 协会器图和难点 | 临图首炼成功额外经验 |
| --- | --- | --- | --- |
| 一难·入门 | 一品 | 听雪剑，直脊开平槽，金铁与水行寒露相合 | 0 |
| 二难·熟手 | 三品 | 松影杖，保持杖心灵脉通畅 | +2 |
| 三难·精工 | 五品 | 归潮刀，既要收出回锋，还要同炼金铁和木料 | +4 |
| 四难·繁工 | 七品 | 金翎枪，叠翎护锋，同时处理金火相克 | +6 |
| 五难·绝艺 | 九品 | 惊雷枪，四重雷纹逐层套合 | +8 |

低于建议师阶仍可尝试。首制时，每两次升品能抵消一级工序负荷；未抵消的每级降低 3 个百分点成功率和 1.5 个百分点返材率。图样本身每高一难另降低 0.5 个百分点成功率。败炉可获得本炉失败经验，额外的临图研习经验只在成功时发放。[器图评级](../server-go/smithing_difficulty.go) · [协会纹路与器图](../server-go/smithing_patterns.go)

## 用一炉听泉杖核对输入与产出

首次可领寒纹铁 3 份、云纹木 3 份、寒露液 2 份、妖兽皮 2 份。用协会原方依图铸造，整包刚好够做一件云纹法衣、一面寒光护心镜和一双踏风灵靴，还余寒纹铁 1 份。可先选听泉杖器胚、松炭炉火、黄阶下品，投入云纹木 2 份和寒露液 1 份。这三份材料符合听泉杖的示范配方。保持配方，改用青泉阴焰再估一次，能直接比较两种火候。器胚是工坊提供的可复用形制，炉火是可选的炉种。首包领完后，每次补料消耗 120 灵石。

| 时点 | 玩家看到什么 | 存档发生什么 |
| --- | --- | --- |
| 选材与估火候 | 当前炼器师与纳气功法、材料余量、炉火、目标品阶、成功率、返材概率、成色和经验修正 | 仅读取当前能力和选料 |
| 开炉成功 | 成品阴阳、五行、主气、品阶、具体词条与数值、本炉工艺 | 扣料、记经验、建立玩家作品模板，纳戒收到一件成品 |
| 开炉失败 | 失败结果、所得经验、各材料实际返还份数 | 逐份判定返料，只扣损耗的份数，保存失败回执 |
| 纳戒及交易 | 名称、品阶、作者和成品词条，奇珍阁可按模板 ID 或武器名称搜索在售品 | 成交后变更持有人。作品保留作者、数值与模板 ID |

## 三类来源，四种工艺收益

炼器师读取角色生活职业栏中类型为 2 的炼器师，与工坊保存的进度比较后取较高者。未入职也可从一品起学。经验按一至九品晋阶表累计，炉前可查看距晋品还差多少，出炉可看到本炉实得和是否晋品。功法读取角色已装备的纳气功法，使用实际五行与品阶，无功法时按中性关系计算。[原炼器师晋阶表](../server/data/config/xzjlianqilist.json)

| 来源 | 配置示例 | 在开炉时如何使用 |
| --- | --- | --- |
| 炼器师品阶 | 一品有「凝形」，九品有四种工艺词条 | 对本角色的每一炉生效 |
| 炉火 | 黄下松炭炉火有「凝形」，玄中青泉阴焰有「护材」「淬灵」 | 炉火自身提供收益，其五行还分别与器胚及材料比较 |
| 目标品阶 | 黄玄地天分别带 1、2、3、4 种工艺词条 | 目标有独立的炼制难度。精模可达目标，良模和粗模按命中锤数下调成品品阶 |
| 纳气功法与投料 | 生、克、被生、被克、同属、中性 | 功法与炉火各比较一次器胚，并按实际份数加权比较各材料。功法品阶提高会放大自身的五行作用 |

「凝形」调整成功率。「护材」调整失败时每份材料收回的概率。「淬灵」推动每条成品数值在本品质区间内向高端或低端移动。「悟工」调整实际所得经验。一品成功基础经验 10 点，失败 2 点。二至九品按本品门槛除以 12、14、16、18、20、22、24、26 次向上取整；所炼建议师阶低于本人 2–3 品、4 品以上时分别减半、减为四分之一，败炉取五分之一，经修正后四舍五入，至少 1 点。临图成功的额外研习经验随后计入，实得经验以九品圆满所剩容量为上限。每 100 个基点表示 1 个百分点或 1% 的修正，取决于该项的含义。

每种炉火另有建议师阶。越阶掌火会降低成功率、败炉返材及成色，同时提高修习经验修正。师阶高于炉火要求时，使用熟悉的火更稳，最多计四品余量。可以在相同器胚、目标与投料下换火，直接比较炉析，选择稳妥成器、护住珍材，或冒险练手。

基础成功率 70%，基础返材率 10%。加上师阶、火焰、目标工艺、目标难度及生克修正之后，还会计入两项选材差异。第一项是器胚与材料的加权平均档位和目标档位之差，器胚计两份。每高一档加 1 个百分点成功率、120 基点成色。第二项是命中器胚配方的材料份数占比，全部命中时加 2 个百分点成功率、300 基点成色。概率限制在 0%～100%。[工艺计算](../server-go/internal/affinity/forge_plan.go)

## 品阶如何决定武器词条

当前工作簿设为黄阶 1 条，玄阶 2 条，地阶 3 条，天阶 4 条，同一件作品的词条种类互异。上中下规定各条数值两端。例如攻击力的下品为 **+0.80%～1.60%**，中品为 **+1.65%～2.60%**，上品为 **+2.70%～4.00%**。因此玄阶上品有两条上品区间的词条，天阶下品有四条下品区间的词条。成色修正始终留在对应区间内。旧极品继续供已有物件查询。

开炉成功才抽取成品。器胚与材料的主辅属性共同决定阴阳和五行，同分时抽签。主气按阴阳配气、五行配气及投料的气性加权抽取。首条取成品主行的侧重，金主攻击、木主生命、水主疗伤、火主炼器、土主防御。其余词条受阴阳侧重、材料和器胚的固有词条影响，材料气性与成品主气吻合时权重进一步提高。[成品生成](../server-go/internal/affinity/forge.go)

## 总表、细表和稳定引用

| 策划表 | 索引 | 负责的数据 |
| --- | --- | --- |
| 物品总表、对象属性、材料表、武器表 | 模板 ID → 对象 ID、分类 ID、品阶 ID | 器胚和材料的主辅属性与形制 |
| 造物用料 | 产物模板 ID × 材料模板 ID | 各器胚的配方亲和及份数 |
| 词条数量、词条区间 | 阶 ID → 数量；词条键 × 品质 ID → 基点上下限 | 控制成品与工艺词条，两类区间分别导出为 `affixRanges` 和 `forgeEffectRanges` |
| 物品词条 | 模板 ID × 属性键 | 每个静态模板的固有词条和数值 |
| 炼器工艺 | 师阶 ID、炉火 ID、目标品阶 ID、五行关系键 | 工艺条目、来源品阶、火焰五行和目标难度 |
| 功法工艺 | 玩法键 × 功法类型 ID × 功法品阶 ID | 已装备纳气功法用类型 3，按该功法品阶取五行作用倍率，分子和分母均为整数 |
| 运行时作品 | `ugc.<ID>` → 作品，纳戒实例 `GoodsId` → `TemplateId` | 作者、分类、器胚、用料、品阶、已揭示的词条与工艺快照 |

要调整某一阶的条数，先改「词条数量」，再同步该阶模板和工艺来源的固定条目。导出器会指出数量不符的模板或来源。同一张炉火表可继续加火种。增加一种器胚时，登记武器叶子分类、明确的阴阳/主行/主气、常规品阶、固有词条，再至少配一种材料。新的材料通过材料分类和模板键加入选料目录，玩家获得该模板的可用物品后即可投入。后续炼丹、画符等可以复用品阶、品质区间、物品和属性表，单独增加对应的工艺来源和产物结算。作品使用新分配的模板键，后续调表不会重新计算已经出炉的作品。

## 工坊协议

默认 Go 服务读取数据目录中的炼器配置。显式启用只读接口预览时，需同时启用 `-interface-writes` 才能使用工坊。炼器协会沿用原有境界门槛，主城装备页另有直接入口。

| 指令 | 功能 |
| --- | --- |
| 1008066 | 炼器协会，工坊启用时回传入口标识 |
| 4901020 / 4901024 | 目录与可用数量 / 按当前角色能力估火候 |
| 4901022 / 4901021 | 领料或付费补货 / 提交开炉 |
| 4901025 / 4901026 | 同模验料预览 / 事务性批量浇铸与重试回执 |
| 4901027 | 领取一件已认主的协会样品 |
| 4901023 / 1004018 | 公开作品模板 / 纳戒与市场装备详情 |
| 1006008 / 1006001 / 1006010 | 固定价挂单 / 查询在售条目 / 按挂牌号成交 |

玩家自定的作品名用于展示和搜索，同名作品各有独立模板。服务器按角色与本次请求号生成作品 ID，按原子事务结算扣料、经验、回执和成品。客户端断线后重交同一请求，会取回原次结果。已锁定、绑定、穿戴或正在传物的材料不可投入。保存失败、缺料或成品放不进纳戒时，整笔事务回滚。
