# 地域、修士与物产

从「地域总表」找到郡号，就能查到当地适合哪种功法、哪种作物，以及哪些怪物、灵植与矿藏会出现。反过来也可以从材料模板找到适用工艺，再查应该去哪个郡、找资源点还是找怪。本轮数值是可修改的策划样例。现有战斗服继续使用原掉落配置。[策划工作簿](../server/data/config_excel/修仙属性基础表.xlsx) · [属性总纲](cultivation-affinities.md)

## 六郡分别适合做什么

现有地图根节点为修真界 `1`，其下有 4 块大陆、5 个洲、6 个郡。郡作为本版的「地区」。城市、城内设施和妖兽林均保留原地图 ID，通过所在地归到郡。下表列的是单项**基础值**。修炼和种植按比例增加所得或进度，炼器、炼丹、画符按百分点调整成功率，克制按比例增加对目标五行怪物的伤害。地图编号来自完整工程的 `game_map.go`。

| 大陆／洲／地区 | 环境 | 这一郡的地利样例 |
| --- | --- | --- |
| 东荒／青云洲／临仙郡 1111 | 阳木·风 | 木行纳气所得 +0.95%，凝露草等木行灵植生长 +0.78% |
| 东荒／青云洲／朝露郡 1112 | 阴木·润 | 木行灵植生长 +1.35%，示例为青芽种子；以木行主材炼丹，成丹率 +0.72 个百分点 |
| 东荒／落日洲／云梦郡 1121 | 阴水·幻 | 梦泽莲等水行灵植生长 +1.25%，水行符墨成符率 +0.97 个百分点 |
| 南岭／紫霞洲／紫霞郡 1211 | 阳火·炎 | 火行器胚成器率 +1.40 个百分点，对金行妖兽伤害 +0.86% |
| 西漠／黄沙洲／沙海郡 1311 | 阳土·燥 | 锁砂棘等土行灵植生长 +0.98%，土行器胚成器率 +0.91 个百分点 |
| 北冥／玄冰洲／寒渊郡 1411 | 阴金·寒 | 金行器胚成器率 +1.15 个百分点，对木行妖兽伤害 +0.71% |

## 在地修士怎样改变地利

大陆、洲、郡都可以设置词条。按「效果键 × 目标五行」沿父链继承，较近层级覆盖同一项。朝露郡的木行生长读本郡的 135 基点，东荒的基础值不会再叠一次。寒渊郡可以同时保留北冥的水行修炼地利和本郡的金行修炼地利。

- **基础值**取自「地域词条」。每项分别登记作用对象、参与共鸣的五行和展示短语。克制词条要写明受击目标，例如「木根破土」针对土行怪。
- **自然浮动**按周期、地区和词条稳定取数。本轮样例每项最多上下 6 基点，同周期反复预览会得到相同结果。
- **修士贡献**只统计输入快照中位于本郡的角色，每个角色只计一次。先取已装备纳气功法的五行，缺失时取数值最高的正灵根，平手按金木水火土顺序。无可用五行的角色只计人数。按「修士五行 → 词条共鸣五行」分别算同属、相生、被生、相克、被克，先合计正负，再对每条封顶 ±12 基点。快照可以是当前在线角色子集，也可以是选定的角色存档，预览按实际提供的口径计数。
- **展示值**为基础值、自然浮动、修士贡献之和。以朝露郡为例，三名木行修士贡献 +9 基点；木行灵植基础生长 +1.35%，修正后为 +1.44%，再加本周期最多 ±0.06%。换功法或迁出郡后，下一份快照会反映变化。

## 怪物、资源点和材料如何对上

| 查什么 | 从哪些键往下查 |
| --- | --- |
| 这个郡能遇到谁 | 郡 ID → 地区怪物 → 怪物 ID → 怪物图鉴与属性对象。区分原项目动物、人形的类型和图标，新设物种独立登记 |
| 打一只怪能得什么 | 怪物 ID → 怪物产出 → 郡与怪物档位 → 材料模板、独立掉率、最少和最多份数 |
| 去哪里采药、开矿 | 郡 ID × 采法 ID → 地区物产 → 材料模板、相对丰度和份数 |
| 一种材料怎么用 | 模板 ID → 物品分类及属性对象，再查资源用途、造物用料。种植用途区分播种、培植和田间辅料 |
| 反查某材料的来源 | 运行配置 `resourceSources[材料模板]` 给出直接采集、怪物特色掉落及旧服通用物料类型的引用。加工材料另查同模板键的 `creationInputs`。通用怪物掉落须结合该怪的本郡栖息记录。按玩法查询则读 `systemResources[玩法键]` |

在图鉴选择具体妖兽林子图后，会按战区群落筛选怪物，外围、深处和兽王巢分别读取其波位。六郡的 108 个子图、41 种对手和查表例子见[妖兽林地与怪物图鉴](bestiary.md)。

「地区怪物」和「地区物产」登记当地候选与基础权重。「生态亲和」再比较郡与候选的阴阳、五行生克、主气。怪物偏移最多 ±3%，直接采集资源最多 ±3.5%。相遇概率只在同郡同档的合格怪物中归一，资源点概率只在同郡同一采法内归一。候选的实际票数为 `基础权重 × (10000 + 亲和基点)`。该写法保留稀有候选的小幅差异。

「怪物产出」单独登记**击败一只该怪后**的掉率。普通、精英、兽王分别读一列，100 基点为 1%，命中后在最小至最大份数间等概率取整数。同次击败可产出多种材料。范围 `0` 表示该怪全部栖息郡；具体郡可以覆盖同一种材料的通用行。兽王池只包含允许成为兽王的种类。原通用掉落与特色产出之间的沿用关系请查「旧掉落对照」及旧服结算。旧服波次与奖励取自完整工程的 `battle_monsters.go` 和 `battle_rewards.go`。

### 从怪物追到一份成品材料

| 在哪里找谁 | 特色产物 | 普通／精英／兽王单只掉率 | 材料有什么用 |
| --- | --- | --- | --- |
| 紫霞郡的赤炎狼 | 焰纹狼牙 ×1 | 18%／36%／69% | 炼器的器件材料 |
| 同一只紫霞赤炎狼 | 阳燧晶 ×1～2 | 3.5%／6.5%／12% | 炼器器件、阵眼材料。也可在紫霞郡或沙海郡采矿获取 |
| 朝露郡的青木猿 | 逐风兽筋 ×1 | 17%／35%／66% | 可作炼器器件或符笔材料，现有逐风弓配方需要 1 份 |
| 同一只朝露青木猿 | 凝露草 ×1～2 | 6.2%／10.5%／18% | 可繁育植株或炼丹主药；凝露丹配方还需寒露液 |

例如玩家缺逐风兽筋，可以从逐风弓的「造物用料」找到材料模板，再顺「怪物产出」查青木猿，最后到「地区怪物」选栖息地。同一材料用于符笔时沿用这个模板。导出时，材料的用途也会并入各玩法的属性对象索引。

## 扩展与复核

1. 增地区时在「地域总表」指定真实上级，填写阴阳、主五行和主气。先读父级已经提供的地利，再加本地特有条目。
2. 增怪物时关联属性对象，登记栖息郡和各档产物。增灵植或矿物时先查已有模板，新增品类按材料表、对象属性和物品词条的要求填写。
3. 用同一材料模板登记采集、掉落及多种工艺用途；首轮填表即可检查从郡到物品及从物品回郡的两个方向。
4. 重新导出双包，再用离线预览对照。同样地区与周期分别使用空快照和示例快照，即可看到纯粹由修士产生的差异。

```sh
python3 tools/export_affinities.py
python3 tools/export_affinities.py --check
python3 tools/preview_region.py --region 1112 --period 7
python3 tools/preview_region.py --region 1112 --demo --period 7 --ecology
python3 tools/preview_region.py --region 1211 --ecology --tier 4
```

要查看自己提供的角色快照，把命令中的 `--demo` 换成 `--roles /实际路径/roles.json`。工具只读指定文件，按现有 `MapId`、已装备功法或灵根汇总；输出包含人数和五行分布。加 `--json` 可取机器可读的同一结果。

## 设计参考

《阿尔比恩》给不同地貌配置不同的天然资源组合，例如山地与沼泽的资源清单有别。本表借用这个做法，先给各郡设置可遇到的资源，再用属性和权重区分常见与稀有。[官方新手指南](https://albiononline.com/news/new-player-guide)

《怪物猎人》的大型怪物记录可查栖息地、属性特征与可获得的材料。本表将这几项拆到同一怪物 ID 下，分别维护地点、五行气性、怪物档位和材料用途。[Capcom 官方狩猎手册](https://game.capcom.com/manual/Multi-Platform/en/xone/page/6/6)

《激战2》的区域事件会响应现场玩家，并随参与情况改变。这里采用「由当地角色参与改变当地状态」的思路，具体实现为有上下限的修士五行共鸣。上述基点、封顶与掉率均为本项目的首轮设计值。[ArenaNet 动态事件说明](https://www.guildwars2.com/en/the-game/dynamic-events/)
