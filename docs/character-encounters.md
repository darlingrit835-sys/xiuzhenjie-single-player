## 从战区查到人物再查掉落

`1112W22` 是朝露郡二号妖兽林深处。沿地图索引查战区，再在「修士行迹」查到精英档的槐素秋。她的编定面板有气血 1,580、灵力 530、攻击 118、防御 143、身法 81、神识 178。在当前策划下，战胜她后有四个独立的稀有掉落判定。

| 奖励 | 模板 | 单次精英掉率 | 命中数量 |
| --- | --- | ---: | ---: |
| 槐阴氏祖传心法摹本 | 功法 73017 ＋ 通用秘籍载体 | 1.60% | 1 |
| 玄龟炼体术摹本 | 功法 72005 ＋ 通用秘籍载体 | 1.60% | 1 |
| 听竹铃 | obj.reed_bell | 0.85% | 1 |
| 青脉丹 | obj.qingmai_pill | 5.20% | 1～2 |

同一宝库也服务同郡的其他人物。人物掉落先用已修功法及随身物品筛去不相符的条目，再按普通／精英／首领档分别取基点；档位 ID 沿用 1／3／4。每个条目独立掷取一次，命中后在数量区间内等概率取整数。单次可以无收获，也可以命中多项。「修士行迹」的相对权重只在同一战区、同一档的人物候选间使用。出现概率和击败后的掉率是两次不同的判断。

怪物从「妖兽宝库」查专库；没有专库时由战区所在郡查「地域宝库」。两者取一个，另保留生态表里原有的妖兽材料产出，统计时能区分材料和奇遇战利品。直接预览郡宝库可指定真实战区。发布到服务端时由同一击败回执负责材料与奇遇各自的一次结算，重复请求返回原结果。

## 九张表怎样关联

| 策划表 | 运行包内 characters 子表 | 关键引用 |
| --- | --- | --- |
| 修士名录、修士面板 | templates、panels | 人物 ID → 家乡郡、阴阳五行主气、等级、宝库和六项结算面板；名字、生平进中文包 |
| 修士所学、随身器物 | methods、equipment | 人物 ID → 途径 ID → 功法数字 ID；人物 ID → 槽位 ID → 物品键 |
| 修士行迹 | encounters、mapsByCharacter | 战区 ID → 人物、档位和权重；反查人物与档位得到可遇战区 |
| 奇遇宝库、奇遇掉落 | pools、rewardEntries | 宝库 ID → 条目 ID → 奖励类型、功法／物品模板、三档掉率、数量区间 |
| 地域宝库、妖兽宝库 | regionPools、monsterPools | 郡或图鉴物种 → 宝库 ID |

随身槽 1 为武器、2 为法器、3 为符笔或阵具、4 为随身丹符。面板是已计随身能力的战斗快照，读取面板时不再重复叠加所带物品词条。新增修士时可复用旧法器与旧秘籍，也能在同类表登记新模板。当前等级必须满足所配功法与单修、兼修组合门槛。新增战区先在「林地战区」登记，人物行迹只能选该战区实际开放的档位。[战区、物种与产出](region-ecology.md) · [功法与兼修](cultivation-methods.md)

听竹铃、照潮珠、定砂印各有自己的物品模板、阴阳五行主气、品阶、词条和造物用料，既可列入敌方宝库，也能反查原料。寒光护心镜复用原物品模板。秘籍掉落生成持有物 `obj.method_manual`，同时保存其功法模板 ID 与发布版本。相同载体的不同功法、不同版本不能合堆；装备和拍卖仍按作品版本与具体物品实例交易。角色之后通过研读检查修习条件并写入所学。掉一本书只产生物品，学会功法与装备到对应途径各有独立的状态转换。秘籍载体的静态物品词条随载体显示，不参与角色修炼收益。

## 离线查询

```sh
python3 tools/preview_character.py --character 槐素秋 --map 1112W22 --tier 3
python3 tools/preview_character.py --monster 301 --map 1111W11 --tier 1
python3 tools/preview_character.py --map 1411W63 --tier 4 --json
```

角色和怪物的实战出场、击杀后入纳戒、秘籍研读、交易和战报回执属于上线接入。历史投影可沿用同一套六项面板字段及宝库档位，保存被投影角色当时的数值与装备版本。
