# 画符规则草稿

符方沿用物品模板、品阶和六郡产出。总表新增七张画符细表，登记五个符方、四种符笔和各项工艺修正。澄露墨沿用原键。新登记的符纸、符墨和符笔都有加工配方，原料沿用已建好的种植、采集和怪物产出数据。[修仙属性基础表](../server/data/config_excel/修仙属性基础表.xlsx)

## 从符箓查到产地

| 符箓 | 一批用料 | 主要原料去哪里找 |
| --- | --- | --- |
| 轻身符，黄阶下品 | 青纹符纸 ×4、澄露墨 ×1、云纹木 ×1 | 临仙或朝露采云纹木和凝露草。澄露墨所需寒露液也可从朝露丹师获得，或用凝露草加工 |
| 润泽符，黄阶中品 | 青纹符纸 ×4、澄露墨 ×1、梦泽莲 ×1 | 朝露可找齐主要原料。梦泽莲也可在云梦采集或打幽冥狐 |
| 庚金破甲符，玄阶下品 | 霜芦符纸 ×3、鸣雷墨 ×1、寒渊银砂 ×1 | 寒渊采霜节芦和银砂。鸣雷墨还要鸣雷角，寒渊、临仙、朝露的白泽幼兽可掉落 |
| 引雷符，玄阶中品 | 青纹符纸 ×4、赤绒朱墨 ×1、雷纹豹须 ×1 | 临仙或朝露找青纹符纸原料，紫霞或沙海采赤绒苔、阳燧晶制墨。临仙和紫霞的雷纹豹可掉豹须 |
| 镇壤护符，玄阶上品 | 霜芦符纸 ×3、赤绒朱墨 ×1、镇壤熊爪 ×1 | 寒渊采霜节芦，紫霞或沙海找制墨原料。沙海、寒渊的厚土熊可掉熊爪 |

从「物品总表」取得符箓模板键，在「符方表」查底材、墨、符师门槛和符效键，用同一模板键在「造物用料」查份数。每种加工料也按自身模板展开用料。采集或掉落查「地区物产」「怪物产出」，通用怪物掉落沿栖息郡展开，具体郡的同物品掉落覆盖通用行。寻材工具里的加工用料是制作一份中间品的用量。[地区产出与引用关系](region-ecology.md)

轻身符保留试用轻身符的木风取向，通过原型键引用。新成品使用常规品阶。引雷符的封印法术键指向已有的火行引雷术，和法术共享主行与主气。现有符师职业类型为 3，品阶沿用 0～9。实际接入时从角色的生活职业槽取对应等级。[角色符师读取逻辑](../UnityProject/Assets/Scripts/Assembly-CSharp/XiuZhenJie/RoleManager.cs#L442)

## 成符率、出符和符效

| 来源 | 规则 |
| --- | --- |
| 符方 | 固定符纸、符墨和辅材各自的份数，配置基础成符率、基础张数范围和单张基础符效 |
| 符师品阶 | 「符师工艺」为三个结果分别配置修正。未学习可试画轻身符 |
| 符笔 | 「符笔工艺」引用物品模板，继承品阶、五行与加工用料。符笔作为可重复使用的工具。云木适合入门，玄鳞偏符效，金翎偏稳成和较高符效，赤晶偏出符数量 |
| 功法和五行 | 符笔和已装备的纳气功法各比较符方、符墨和符纸的主五行，权重 60%、30%、10%。同属与相生有正修正，相克与被克会削弱收益。功法品阶通过「功法工艺」的 `inscription` 条目缩放功法自身的五行修正 |
| 画符地点 | 读取当地与符墨五行匹配的成符率词条，计入周期和修士共鸣。云梦的水墨地利同时适用于轻身符和润泽符 |

1. 成符率以基点储存。基础概率加符师、符笔、五行、功法、地利修正，当前上限 98%。
2. 本批成功后等概率抽取基础张数，再乘出符倍率。比如得到 2.4 张，有 40% 的概率出 3 张。倍率区间为 85%～145%，出符至少 1 张，以本批投入的符纸张数封顶。失败出符 0 张。
3. 单张符效按下、中、上品分别在 92%～100%、101%～111%、112%～124% 的区间取倍率。修正在区间内移动结果，累计修正较高时可以稳定达到上限。实际符效为基础值乘倍率后四舍五入。同一成功批次固定符效，移动速度用基点保存，伤害与恢复类用点数保存。

第 7 周期的云梦郡，二品符师用玄鳞符笔和水行纳气功法 `gf_3_3` 画润泽符，空修士快照下成符率 **85.86%**，其中水墨地利贡献 **+1.01 个百分点**。成功后有 **25.52%** 的概率出满 4 张，每张恢复 **93～94 点气血**。

四品符师用火行功法 `gf_3_9` 画引雷符，赤晶符笔与玄鳞符笔的成符率分别为 **79.71%** 和 **76.10%**。成功出满 4 张的概率分别为 **46.58%** 和 **27.05%**。对应单张雷伤为 **151～155** 与 **152～155**。赤晶适合批量画火行符，玄鳞自身的符效修正仍有价值。

## 离线查询与后续接入

```sh
python3 tools/export_affinities.py --check
python3 tools/preview_inscription.py --talisman 庚金破甲符
python3 tools/preview_inscription.py --talisman 润泽符 --rank 2 --brush obj.xuanlin_brush --method gf_3_3 --region 1121 --period 7
```

可用符名、成品模板键或符方键查询。只提供 `--brush` 可以顺带查笔的产地。加 `--json` 可读掉率、采法和加工原料树。地点共鸣可用 `--roles /实际路径/roles.json` 给出角色快照。改表后用 `python3 tools/export_affinities.py` 同步两份导出文件。

接入游戏时，校验角色的符师和功法、持有符笔与符材，再结算消耗、成败、产量和符效。成功批次应保存符方键、成品模板键、实际符效和规则版本。入纳戒、符箓使用、战斗效果与客户端需要继续接入。
