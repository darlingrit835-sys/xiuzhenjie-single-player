## 查表与扩表

| 工作表 | 引用关系 | 用途 |
| --- | --- | --- |
| 修炼途径 | 途径 ID、稳定键、可选旧装备栏 | 增加新修炼方向。旧角色继续使用各自的既有栏位 |
| 功法目录 | 功法 ID → 途径、属性对象、品阶、图标 | 查最低修习等级、基础周天、旧键。中文名按模板保存，可独立于属性对象改名 |
| 功法品阶规则 | 品阶 ID → 入门等级、周天下限与上限 | 校验新作的修习门槛和速度。旧极品专供旧功法 |
| 功法词条 | 功法 ID × 现有词条键 | 引用总表「词条数量」「词条区间」。每阶允许的数目依次为一至四条，同一词条只能出现一次 |
| 原功法效果 | 旧功法的数字 ID × 原效果编号 | 原服面板值独立保存，供兼容读取。单位与新策划词条的基点分开 |
| 功法重数 | 重数 ID → 周天倍率 | 初通 100%、纯熟 120%、圆融 150%。未记录重数的旧角色按一重读取 |
| 兼修组合 | 组合 ID → 等级与可选旧位置码 | 选择单修、双修、三修。原客户端位置码 1 至 6 继续指向原来的三种单修和三种双修 |
| 兼修分配 | 组合 ID × 途径 ID → 本途径效率 | 每种组合可以单独调每路速度。新途径用新增行参与组合 |

**数值示例。** 家传模板 `73017` 引用 `lineage.huaiyin` 的阴木、生气，品阶为玄阶下品，11 级可修习。其基础周天是 3.260，保存为整数 3260。生命上限与疗伤量各占一个词条位，分别为 150、156 基点。作为炼丹或画符的功法，它以木行和玄阶下品查「功法工艺」，当前倍率为 24/20。「照影定心诀」是水行炼神功法，现有工艺只登记了炼气，选为丹火或符墨的配套功法会提示缺少途径配置。

**周天与兼修。** 周天以千分数存储。每条活动途径只取一本已装备功法，其周天乘本功法重数倍率，再乘组合中这条途径的效率。计算时保留整数分子，在最终增加该途径进度时取整并保留余数。不同途径分别积累修为、体魄或神识。正式接入时仍需叠加境界、洞府等角色条件，并分别取各成长目标的上限。当前设计沿用单修 100%、31 级双修每路 70%。三修方案为 51 级开放、每路 50%。旧客户端缺少可区分三修与单修的独立位置码，三修使用新的组合 ID `7`。三修解锁和新词条属于策划值，正式服当前仍按已有逻辑运行。

**玩家创作。** 为作品分配独立的模板 ID、属性对象和图标引用，填途径、阴阳、主行、主气与常规品阶。主表上的旧功法键留空。例如玄阶中品作品有两个词条位，每种词条在自身的中品区间内取值。导表会拒绝越界的基础周天、越级学习门槛、缺失和重复词条、冒用旧功法键或旧极品。一旦落入装备、传承或拍卖实例，使用作品的数字模板及版本识别。改名和替换图标时保留原 ID。

**新修炼方向。** 在「修炼途径」分配新编号和稳定键，在「兼修组合」「兼修分配」登记至少一个单修以及所需的跨途径组合，再加入相应的功法和词条。若要影响工艺，在「功法工艺」为该玩法和途径补齐品阶倍率。导表和离线查算直接读取新行。角色存储、战斗结算与新成长资源的服务端协议仍需要独立接入。

以下命令可检查家传木行功法在工艺中的影响。将 `--method` 改为 `gf_3_2` 可比较旧木行功法同一丹方的倍率。

```sh
python3 tools/preview_alchemy.py --pill 凝露丹 --rank 2 --flame flame.spring --method 73017
python3 tools/preview_inscription.py --talisman 润泽符 --rank 2 --brush obj.xuanlin_brush --method 73017
```

## 无字书册图标

五行决定书衣底色，金用银灰、木用青绿、水用靛蓝、火用赭红、土用黄褐。炼神用月晕、珠扣和细线装，炼体用厚封、护角和革带，炼气用纤维书衣和交结装。每个图标是一张 256 × 256 的透明 PNG，项目中的 Unity 单 Sprite 路径为 `CatalogIcons/Methods/<图标ID>`。中文名称和品阶从界面另行排版。

封面图案跟随稳定的图标 ID。水行的「照影定心诀」取铜镜和水纹，土行的「玄龟炼体术」取龟甲、浪纹和灵珠。一本功法改名仍沿用自己的封面，作品也可在模板中引用已有的图标。新增独立的书册纹样时，在本地图稿添加矢量形状，在作者工具的 `scenes` 为新图标 ID 编排纹样，再把图标加入「图标目录」。新修炼途径可先沿用交结装。绘制过程不读取书名来挑选图案。工具只写 PNG，既有 Unity `.meta` 继续保存每个资源的 GUID。[本地纹样画稿](../art/catalog/method-emblems.svg) · [本地作者工具](../tools/art/render_method_icons.cjs)

本地 Node.js 需能解析 `sharp` 包。以下命令从正式配置及匹配的中文资源读取功法和主五行，重绘书册。可用 `--output` 指定另一目录做比对，或用 `--proof` 输出按功法模板 ID 排序的缩略校样。

```sh
node tools/art/render_method_icons.cjs
```
