# 功能状态与协作待办

基线为 2026-11-19 的 Android **1.3.5（30）**、云端热更 **4** 和完整 Go 测试工程。本地 Java 单机版保留独立的实现与存档，历史能力见[单机改造记录](单机化改造.md)。

**已验证**表示对应流程有现成的测试证据。**部分实现**表示已有业务能力，表中同时列出缺口。**未实现**表示该流程尚无完整业务写入，可有入口、示例、空态、兼容回包或明确拒绝。**待验证**表示代码或构建已存在，仍需补充指定环境的验收。原客户端的每个待接入接口可在[Go 协议缺口清单](Go协议缺口.md)按 Cmd 查找。

## 可接手的世界内容配置

六郡历练地图、怪物面板与抗性、炼气／炼体／炼神功法、命名修士与稀有掉落均有可导出的策划细表。多人留影和玩家作品已定义数字模板、版本、快照与重复结算约束，并提供离线预览。玩法服务、角色授权、Unity 界面与持久化的接入进度仍按下列模块验收。[策划入口与扩展步骤](content-framework.md)

## 开发优先顺序

1. **P0** 搭建可复现的协作分支，补 Android 从安装、建角到主城、历练的真机证据，修复经脉入口后再恢复引导。
2. **P1** 优先补影响经济、进度和多人状态的缺口，包括战斗结算、灵田循环、个人交易、宗门权限和邮件持久化。
3. **P2** 扩展生产、协会、排行榜与活动，推进世界聊天、道侣、ARM64 和鸿蒙。

准备提 PR 时，从[协作指南](../CONTRIBUTING.md)获取复现和验收格式。协议有变动时同步更新[Go 协议缺口清单](Go协议缺口.md)。
