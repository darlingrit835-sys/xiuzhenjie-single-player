# 修真界游戏流程与模块索引

按玩家看到的功能查修改入口。表内附 Unity 控制器、Go 业务规则、配置和改完优先检查的操作。需要追具体请求、字段和响应时，查 [Unity 与 Go 接口对应表](interface-pb/go-interfaces.md)。

## 玩家流程

- **新角色**　启动 → 登录 → 选服 → 选头像、名字、灵根和出生地 → 创建角色 → 进入所在主城。
- **已有角色**　登录 → 选服 → 读取已有角色 → 回到角色所在主城。有离线收益时可在弹窗领取或放弃。
- **首次修行**　主城引导 → 纳戒使用启灵经 → 参悟 → 洞府练功房切换功法 → 开始纳气。回到游戏时按角色保存的引导进度继续。
- **历练**　主城底栏「历练」→ 选择林地和子区域 → 进入战斗 → 结算或主动退出 → 返回主城。首场回归可走紫霞城 → 紫霞郡 → 妖兽林地1 → 外围。
- **日常循环**　修炼与突破提升境界，纳戒整理掉落，装备和技能配置影响下一次战斗。城主府接续主线和领奖，宗门、灵田、坊市、虚神界和道友由各自入口进入。

## 查 Prefab 和业务状态

- **改图和交互。** 对应模块的可编辑窗口在 `Assets/gamedata/prefabs/uiprefabs/window/<模块>`，列表项在 `item/<模块>`，共享美术在 `Assets/Resources/Ink*`。运行时窗口名与 C# 的对应关系从 [场景与窗口归档](interface-pb/windows.md) 或 `GameStart.Register<T>` 查，资源修改时保留 `.meta` 和运行时的逻辑资源键。
- **改规则和存档。** 从窗口按钮和回包找 Cmd，再定位 Go 处理和配置。默认 Go 主流程覆盖登录、建角、任务、修炼、地图、装备和常规历练。部分旁支有可打开的界面，其服务端能力按接口逐条判断。 [客户端调用](interface-pb/calls.md) · [Unity 与 Go 接口对应表](interface-pb/go-interfaces.md)
- **改试用玩法。** `-interface-preview` 启用已注册的试用查询和明确的写入拒绝回包。再加 `-interface-writes`，只开放已实现的拍卖和宗门部分写入。灵田种植与收获、完整社交和其他玩法仍需专门处理。涉及交易、审批或存档的回归使用独立端口和测试存档。 [Go 试用模块与启动说明](../server-go/README.md#接口对应表与试用)

后续可直接提「洞府模块改五行灵气」「主城模块改建筑卡片」或「历练模块改战斗状态栏」，按对应行定位入口和回归范围。
