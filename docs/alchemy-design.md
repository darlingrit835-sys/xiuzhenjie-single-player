# 炼丹配方、火候与留影

洞府炼丹室收录 20 张丹方，丹阶 0～9 各两张。17 种药材来自六郡、历练、灵田、符案与药柜。各方的药效、丹毒、标准回收、推荐用料和平均每粒成本见[丹房收支与用药](丹房收支与用药.md)。配方和定价可以在[修仙属性基础表](../server/data/config_excel/修仙属性基础表.xlsx)调整。

## 原有五方与产区

| 凝露丹，黄阶上品 | 凝露草 ×2、寒露液 ×1 | 朝露郡可采草，丹师可掉寒露液。也可用凝露草 ×3 加工寒露液 |
| 青脉丹，黄阶中品 | 凝露草 ×2、听风青石 ×1、逐风兽筋 ×1 | 临仙郡或朝露郡可采药、采矿，青木猿可掉兽筋 |
| 赤阳振元丹，玄阶中品 | 赤绒苔 ×2、阳燧晶 ×1、焰纹狼牙 ×1 | 紫霞郡或沙海郡可采苔、采晶，赤炎狼可掉狼牙 |
| 镇壤护体丹，玄阶下品 | 锁砂棘 ×2、赤烈砂 ×1、镇壤熊爪 ×1 | 沙海郡可采棘、采砂，厚土熊可掉熊爪 |
| 霜脉清毒丹，玄阶上品 | 霜节芦 ×2、寒渊银砂 ×1、玄水鳞 ×1 | 寒渊郡可采芦、采矿，玄水蟒可掉鳞 |

从「物品总表」取成品模板键，到「丹方表」查主药、起炉条件和药效键，再用同一成品键到「造物用料」查询份数。沿材料模板键查「地区物产」和「怪物产出」。怪物通用产出按其栖息郡展开，指定郡的同物品掉落条目优先。加工料继续沿自己的用料记录查原料。旧筑基丹的品阶 ID 4 保留在「旧极品对照」，本轮的新丹方引用常规品阶。[地区产出规则](region-ecology.md)

## 工作簿与离线估算

| 来源 | 作用 |
| --- | --- |
| 丹方 | 配置基础成丹率、成功后的基础粒数范围、单炉粒数上限、单粒基础药效和最低丹师品阶 |
| 丹师品阶 | 沿用原职业编号 0～9。游戏从角色 `Live1Type` 或 `Live2Type` 读取职业类型 1，将对应等级与丹房修习品阶合并。未学习可以试炼凝露丹或清息散。一品到九品逐步提高成丹、出丹和药效 |
| 丹火 | 共用炉火键、品阶和五行，各自配置炼丹修正。松炭炉火易于起炉，青泉阴焰偏药效，赤阳炉火偏多结丹，星陨真火偏稳成和药效 |
| 功法 | 取已装备的纳气功法 `GongFaNaQi`。其五行参与材料生克，功法品阶按「功法工艺」的 `alchemy` 条目放大自身影响 |
| 五行 | 丹火和功法分别照「炼丹生克」比较材料。主药占 75%，其余材料占 25% 并按份数加权。没有辅材时全部按主药。水生木利于木行丹方，水克火会压低火行丹方收益 |
| 炉址 | 沿地区父链读取与**主药**五行匹配的「成丹率」词条，含当期和修士共鸣修正 |
| 药材估值、丹药调衡 | 配置材料单份参考价、药柜购价、成品三档回收、每粒丹毒，以及固定点数或按服用者属性计算的药效口径 |

原丹师的职业名称与编号见项目配置。原有数量系数供旧炼丹界面的操作速度计算，这份草稿单独定义成功后的粒数。[原丹师职业表](../server/data/config/xzjworldassesselixirlist.json)

1. **成丹率**等于基础概率加各项成丹修正，100 基点为 1 个百分点。当前总概率上限为 98%。炉址加成作用于此项。
2. **出丹数量**在成功后计算。先在丹方的基础粒数范围内等概率取整数，再乘出丹倍率。结果为 2.4 时，有 40% 概率出 3 粒，其余出 2 粒。倍率当前限定为 85%～140%，实际数量至少一粒，并受丹方的单炉上限约束。失败产出 0 粒。
3. **药效**由成品下、中、上品确定倍率区间，当前为 90%～99%、100%～112%、113%～128%。离线估算给出品质档内的药力区间。游戏内同一批次共享丹方、成品模板、品质和药力，换辅材可以在档内调整药力。比例药在服用时按持有者的本层突破门槛或气血上限折算，转手后也适用。

例如，四品丹师用赤阳炉火、火行纳气功法 `gf_3_9`，在紫霞郡第 7 周期炼赤阳振元丹。空修士快照时，离线估算成丹率 **80.21%**。成功后有 **45.30%** 概率出 4 粒，单粒恢复 **69～73 点精力**。换青泉阴焰，同样条件下成丹率为 **76.21%**，成功后 4 粒的概率为 **24.30%**。两种火的成色累计修正使本例单粒药效范围相同。

## 协作与校验

协作者可在同一分支增加丹方。先到「物品总表」「对象属性」「物品词条」登记丹药，再在「丹方表」添加配方及药效，在「造物用料」填材料和份数。已有材料沿用模板键，在「资源用途」补充炼丹用途。在「药材估值」登记新药材的参考价与购价，在「丹药调衡」登记新方的药效口径、丹毒和三档回收价。

```sh
python3 tools/export_affinities.py
python3 tools/export_affinities.py --check
python3 -B tools/alchemy_balance.py --write
python3 -B tools/export_alchemy_board.py --check
python3 tools/preview_alchemy.py --pill 凝露丹
python3 tools/preview_alchemy.py --pill dan.chiyang --rank 4 --flame flame.solar --method gf_3_9 --region 1211 --period 7
```

查材支持丹名、成品模板键和丹方键。估算加 `--json` 可查各工艺贡献、分郡的掉率和加工原料树。需要计入当地修士时，可用 `--roles /实际路径/roles.json` 提供快照。数据、导出和估算已可协作。下节记录游戏内手炼、留影和批次服用的实际规则。

## 09 地火丹房

从洞府的炼丹室进入地火阁。丹房载入 20 张丹方，各方锁定一种主药，用量为 1～5 份。其余位置可空置，也可按喜好从纳戒中投入一至三份辅材，同一种可重复。配料页显示相性、成丹率范围和药力预估。无品丹师可试炼凝露丹或清息散，首次手炼成功升为一品。随后按适阶丹方手炼，每品约 10–26 次适阶成功手炼可晋品或达圆满，低阶丹方积累历练较慢。药柜首次免费发放入门炉材，之后每包 90 灵石。丹谱列出本炉估值与实缺份数，常用药材可以逐味补买，稀有材料可以查看产区或猎物。[互动样稿](../design/修真界UI/09%20炼丹.html)

| 工序 | 操作 | 占火候总分 |
| --- | --- | ---: |
| 温炉 | 铜针顺转，指针进入金色火候弧中心时点击点火 | 25% |
| 合药 | 铜针反转，在药性汇合时定针 | 35% |
| 凝丹 | 最后一段加快、弧区缩窄，在弧心收丹 | 40% |

每步可以等下一圈。金弧中心为 100 分，边缘为 50 分，偏离两个半弧宽时为 0 分。手炼结算时同时扣除材料、写入熟练度、保存留影、将成品收入纳戒。失败也会耗材。已有角色从丹师职业槽和丹房历练记录中取较高丹阶。熟练度按丹方分别积累，手炼成功加 6、失败加 2、复炼每炉加 2，最高 100。

- **辅材相性**取每份辅材对主药的五行关系求平均。辅生主为 +100，同气 +60，主生辅 +35，辅克主 −65，主克辅 −90。只放主药为 0。
- **难度**令 `E = 45 × 丹阶 + 4 × 熟练 + 2 × 辅材相性 − 115 × 丹方所需品阶`。三段序号从 0 起，第 i 段每圈用时为 `2400 − 260i + E` 毫秒，限于 850～3800 毫秒。目标半宽为 `1550 − 235i + E` 基点，限于 450～2300 基点，一整圈为 10000 基点。每次手炼都会重新抽取三个弧心的位置。
- **成丹率**在丹方基础上加丹阶、松炭炉火、丹火和已装配纳气功法的五行修正，再加 `5 × 熟练 + 8 × 辅材相性 + 32 × (火候总分 − 60)` 基点，最终限制在 5%～98%。例如，无品、零熟练、未装配纳气功法时，凝露草两份、寒露液一份炼凝露丹，60 分有 91.60% 成丹率，三步都正中弧心为 98%。
- **品质和药力**在成功后计算。火候总分加上 `2 × 丹阶 + 熟练/10 + 辅材相性/12`，整数除法向零截取。满 90 出上品，满 65 出中品，其余出下品。相性和辅材份数会改变品质区间内的实际药力。回血与修为丹有固定点数及比例两种，回精、清毒丹按点数结算。护体丹每 20 点表列药力抵 1% 战斗气血，受阵师增益，至多 48%。疗伤词条加成实际回血量。强效丹会积毒，服后丹毒超过 100 或当前没有收益时，药丸留在纳戒。
- **留影直炼**自动保留每张丹方手炼成功的最高品质和当炉用料。直炼必成，照常扣除所选材料，沿用留影品质与工艺药力修正。换辅材会在该品质档内改变单粒药力。使用原料可复现原留影的单粒药力。三／六／九品解锁每批 5／10／20 炉，逐炉照常消耗材料、独立计算粒数与实际回收。复炼每炉增加 2 点本方熟练及半份相应丹师经验。每次手炼 1 精力，留影整批耗精力为炉数除以 3 后向上取整。

游戏中使用 Go 服务端和对应 Unity 客户端。游戏内的手炼和换料直炼回执可对照[运行截图](炼丹火候与留影.jpg)。文中前半部分的多丹火、炉址与周期修正可在离线工具中推演。09 互动样稿使用本地示例角色和药匣，可切换丹阶体验难度。[配方与算法](../server-go/alchemy_rules.go) · [结算与存档](../server-go/alchemy.go)
