# 炼丹规则草稿

这份草稿适合共同审定配方、产区和工艺数值。工作簿「丹方表」配置五种入门和进阶丹药，沿用现有六郡的灵植、矿物和妖兽材料。[修仙属性基础表](../server/data/config_excel/修仙属性基础表.xlsx)

## 五个丹方

| 丹药 | 主药与配料 | 可配齐一炉的地区 |
| --- | --- | --- |
| 凝露丹，黄阶上品 | 凝露草 ×2、寒露液 ×1 | 朝露郡可采草，丹师可掉寒露液。也可用凝露草 ×3 加工寒露液 |
| 青脉丹，黄阶中品 | 凝露草 ×2、听风青石 ×1、逐风兽筋 ×1 | 临仙郡或朝露郡可采药、采矿，青木猿可掉兽筋 |
| 赤阳振元丹，玄阶中品 | 赤绒苔 ×2、阳燧晶 ×1、焰纹狼牙 ×1 | 紫霞郡或沙海郡可采苔、采晶，赤炎狼可掉狼牙 |
| 镇壤护体丹，玄阶下品 | 锁砂棘 ×2、赤烈砂 ×1、镇壤熊爪 ×1 | 沙海郡可采棘、采砂，厚土熊可掉熊爪 |
| 霜脉清毒丹，玄阶上品 | 霜节芦 ×2、寒渊银砂 ×1、玄水鳞 ×1 | 寒渊郡可采芦、采矿，玄水蟒可掉鳞 |

从「物品总表」取成品模板键，到「丹方表」查主药、起炉条件和药效键，再用同一成品键到「造物用料」查询份数。沿材料模板键查「地区物产」和「怪物产出」。怪物通用产出按其栖息郡展开，指定郡的同物品掉落条目优先。加工料继续沿自己的用料记录查原料。旧筑基丹的品阶 ID 4 保留在「旧极品对照」，本轮的新丹方引用常规品阶。[地区产出规则](region-ecology.md)

## 怎么计算一炉

| 来源 | 作用 |
| --- | --- |
| 丹方 | 配置基础成丹率、成功后的基础粒数范围、单炉粒数上限、单粒基础药效和最低丹师品阶 |
| 丹师品阶 | 沿用原职业编号 0～9。未来从角色的 `Live1Type` 或 `Live2Type` 读职业类型 1，对应等级字段为丹师品阶。未学习可以试炼凝露丹。一品到九品逐步提高成丹、出丹和药效 |
| 丹火 | 共用炉火键、品阶和五行，各自配置炼丹修正。松炭炉火易于起炉，青泉阴焰偏药效，赤阳炉火偏多结丹，星陨真火偏稳成和药效 |
| 功法 | 取已装备的纳气功法 `GongFaNaQi`。其五行参与材料生克，功法品阶按「功法工艺」的 `alchemy` 条目放大自身影响 |
| 五行 | 丹火和功法分别照「炼丹生克」比较材料。主药占 75%，其余材料占 25% 并按份数加权。没有辅材时全部按主药。水生木利于木行丹方，水克火会压低火行丹方收益 |
| 炉址 | 沿地区父链读取与**主药**五行匹配的「成丹率」词条，含当期和修士共鸣修正 |

丹师职业名称与编号来自完整工程的 `xzjworldassesselixirlist.json`。旧炼丹界面用数量系数计算操作速度。这份草稿单独定义成丹后的粒数。

1. **成丹率**等于基础概率加各项成丹修正，100 基点为 1 个百分点。当前总概率上限为 98%。炉址加成作用于此项。
2. **出丹数量**在成功后计算。先在丹方的基础粒数范围内等概率取整数，再乘出丹倍率。结果为 2.4 时，有 40% 概率出 3 粒，其余出 2 粒。倍率当前限定为 85%～140%，实际数量至少一粒，并受丹方的单炉上限约束。失败产出 0 粒。
3. **药效**由成品下、中、上品确定倍率区间，当前为 90%～99%、100%～112%、113%～128%。成功后在本档抽取整数基点，再加药效修正并压回本档。单粒基础药效乘该倍率，四舍五入得到实际效果值。同一成功批次共享药效。规则落地时可给批次保存丹方键、成品模板键、单粒效果值与规则版本。

例如，四品丹师用赤阳炉火、火行纳气功法 `gf_3_9`，在紫霞郡第 7 周期炼赤阳振元丹。空修士快照时，离线估算成丹率 **80.21%**。成功后有 **45.30%** 概率出 4 粒，单粒恢复 **69～73 点精力**。换青泉阴焰，同样条件下成丹率为 **76.21%**，成功后 4 粒的概率为 **24.30%**。两种火的成色累计修正使本例单粒药效范围相同。

## 协作与校验

协作者可在同一分支增加丹方。先到「物品总表」「对象属性」「物品词条」登记丹药，再在「丹方表」添加配方及药效，在「造物用料」填材料和份数。已有材料沿用模板键，在「资源用途」补充炼丹用途后即可被引用。配方量、丹火偏向、职业加成与五行系数均可从工作簿调整。

```sh
python3 tools/export_affinities.py
python3 tools/export_affinities.py --check
python3 tools/preview_alchemy.py --pill 凝露丹
python3 tools/preview_alchemy.py --pill dan.chiyang --rank 4 --flame flame.solar --method gf_3_9 --region 1211 --period 7
```

查材支持丹名、成品模板键和丹方键。估算加 `--json` 可查各工艺贡献、分郡的掉率和加工原料树。需要计入当地修士时，可用 `--roles /实际路径/roles.json` 提供快照。数据、导出和估算已可协作。丹方平衡、批次入袋与正式服用效果待后续审定和接入。
