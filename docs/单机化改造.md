# 单机化改造明细

三处改动，前两处决定「能不能连上」，第三处决定「玩不玩得下去」。

## 1. 客户端：登录地址改成 127.0.0.1

客户端是 Unity Mono 工程，服务器地址硬编码在 `Assembly-CSharp.dll` 的
`XiuZhenJie.Constants` 静态构造里，热更地址在 `Resource.dll` 里。

原值：

```csharp
// XiuZhenJie/Constants.cs（.cctor）
LoginServerIP   = "10.0.2.2";   // MuMu 模拟器用的宿主机地址
LoginServerPort = 9443;
```

用 Mono.Cecil 直接改 IL 里的 `ldstr` / `ldc.i4` 操作数（不重建方法体，避免 Mono 校验失败）：

```powershell
if ($ins[$i].OpCode.Name -eq 'ldstr' -and $ins[$i+1].Operand -match 'LoginServerIP') {
    $ins[$i].Operand = '127.0.0.1'
}
```

`Resource.dll` 里的 `https://10.0.2.2:9443/...` 同理改成 `https://127.0.0.1:9443/...`。

改完必须**重新签名**（改内容会让原 v2 签名失效）：删掉 `META-INF/*.SF,*.RSA,*.MF` →
`zipalign -f -p 4` → `apksigner sign --ks sign.keystore ...`（v1+v2+v3）。
完整脚本见 `tools/patch_apk.ps1`。

> 注意：`targetSdkVersion=32`，Android 11+ 只认 v2 及以上签名，`jarsigner` 只签 v1 装不上。

## 2. 服务端：下发的选服地址也要改

账号服 `/login` 返回的 `gameServersInfoList[].serverIp` 来自服务端配置，
客户端登录成功后用这个地址去连游戏服 —— 只改客户端 IP 是不够的。

```java
// Config.java
- public static final String PUBLIC_IP = "10.0.2.2";
+ public static final String PUBLIC_IP = System.getProperty("xzj.publicIp", "127.0.0.1");
```

`data/config/server.json` 里 `publicIp` 同样是持久化的旧值，要一起改：

```json
{ "publicIp": "127.0.0.1" }
```

## 3. 服务端：修「进了战斗地图出不来」

客户端 `BattleWnd.LiKaiBtnClick`（离开战斗按钮）有这么一段硬拦截：

```csharp
if (Role_Entity.BattleGuideVal != 100 && GuideManager.YinDaoJilu1.YinDaoShu < 16)
{
    PopUpAttention("刘老六说地图进度需要打到35%后击杀领主，还是先别离开此地了吧", ...);
    return;   // 直接 return，走不到「是否离开战斗」
}
```

`BattleGuideVal` 是服务端下发的战斗引导进度（1→5，满 5 记 100），
`YinDaoShu` 是客户端本地的新手引导步数。私服没补全整条引导触发链，
两个条件永远不满足，玩家进了战斗地图就被永久锁死。

修法：登录响应里直接把战斗引导视为已完成。

```java
// RoleLoginHandler.java
- b.setBattleGuideVal(num(r, "BattleGuideVal"));
+ b.setBattleGuideVal(ServerConfig.get().completeBattleGuide ? 100 : num(r, "BattleGuideVal"));
```

开关放配置里，想恢复原版引导流程把 `completeBattleGuide` 设为 `false`：

```json
{ "completeBattleGuide": true }
```

## 手机怎么接电脑上的服务端

客户端连的是 `127.0.0.1`，服务端跑在电脑上，所以用 adb 反向映射：

```bat
adb reverse tcp:9443  tcp:9443    :: 账号服（HTTPS）
adb reverse tcp:17666 tcp:17666   :: 游戏服
adb reverse tcp:17667 tcp:17667   :: 战斗服
```

`adb reverse` 在拔插数据线 / adb 重启后失效，所以启动脚本每次都重建一遍映射。

## 踩过的坑

1. `zipalign` 之前必须删掉旧签名文件，否则 `apksigner` 报签名块冲突。
2. PowerShell 5.1 按 GBK 解析 `.ps1`，含中文且「UTF-8 无 BOM」会直接语法报错 ——
   本项目脚本统一存成 **UTF-8 BOM**，`.bat` 只保留 ASCII 内容。
3. Java 工程用 `user.dir` 定位 `data/`，必须 `cd server` 再启动，不能从别处带绝对 `-cp` 起。
4. `Config` 是 `static final`，改值不重启进程不生效。
