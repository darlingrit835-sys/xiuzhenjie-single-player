# 物品分类与玩家创制

材料和武器各有一张专用细表，所有可引用的物品先在「物品总表」登记。分类说明“它是什么”，属性说明“它有什么偏性”，用料说明“造一件要投入什么”。同为剑的两件武器可以分属不同五行；两把同属阴金寒气的剑也可以用不同器胚制成。[策划工作簿](../server/data/config_excel/修仙属性基础表.xlsx) · [属性框架总纲](cultivation-affinities.md)

## 查一件物品

| 要查什么 | 从哪张表、用哪个键 |
| --- | --- |
| 名称、分类、原型 | 用模板键查「物品总表」。`id` 是稳定键，名称可重名。 |
| 草木、矿砂、金材，或剑、刀、枪等形制 | 从总表的 `categoryId` 查「物品分类」；沿 `parentId` 向上查可汇总同一大类。 |
| 阴阳、主辅五行、主辅气 | 从总表的 `profileId` 查「对象属性」。具备相应主属性时，`classId` 可定位衍生类别。 |
| 天地玄黄、上中下 | 从总表读取整数 `gradeId`，到「品阶表」查档位与名称，到「词条数量」「词条区间」查条数和上下限。历史极品到「旧极品对照」查。 |
| 材料形态、可用工序与加工特性 | 用同一个模板键查「材料表」；界面从中文资源的 `materialDetails[模板键]` 读取说明。 |
| 武器怎么持握、如何作用、对器胚有什么要求 | 用同一个模板键查「武器表」；界面从中文资源的 `weaponDetails[模板键]` 读取说明。 |
| 创制时消耗什么 | 在「造物用料」登记产物、材料和数量。运行配置的 `creationInputs[产物键][材料键]` 是制作一件产物所需的整数份数。 |
| 哪些配方需要一种材料 | 在 Excel 按材料模板键筛选；Go 查询包加载配方后支持按材料索引查产物。 |

每件物品选择一个叶子分类。「材料表」和「武器表」各为对应模板保留一行。丹药、符箓、灵土、护具等可直接登记在总表，再按玩法增加专用规则。物品分类独立于它能参与的活动，一种材料可同时用于炼丹、制墨和拍卖。现有“持用方式”“加工特性”供展示。如果新增可计算的射程、蓄力或淬火属性，应新建有单位的数值字段，并按模板键关联。

除配方合成外，材料可来自地区采集点或怪物掉落。在「资源用途」按模板查用途，在「怪物产出」「地区物产」按同一键查来源。[地区物产与怪物图鉴](region-ecology.md)

## 玩家创制示例：先炼铁，再铸剑

| 产物 | 取自哪个原型 | 实际投入的材料 | 此次建立的记录 |
| --- | --- | --- | --- |
| 霜纹铁 `made.frost_iron` | 一阶陨铁 `yun_tie_1` | 2 份一阶陨铁、2 份寒露液、1 份赤烈砂 | 新材料，阴金主寒，品阶 ID 6（玄阶中品） |
| 霜纹剑 `made.frost_sword` | 五行聚灵剑 `wu_xing_ju_ling_jian` | 3 份自制霜纹铁、1 份云纹木 | 新武器，阴水主寒，品阶 ID 7（玄阶上品） |

原型记录设计来源。只有列入「造物用料」的物品才按份数消耗。第一步中陨铁既是原型也是材料；第二步引用了聚灵剑的形制，实际消耗的是铁和木。原项目的一阶陨铁和五行聚灵剑在玄天楼都记为 `FiveElement=0`，新品的五行由自己的属性对象明确赋予。原数据见完整工程的 `xuantianlougoods.json`。

## 增加新材料、新武器或新门类

1. **选分类。** 已有叶子可直接复用。要新增鞭类武器，先在「物品分类」里加一个稳定键，如 `wp.whip`，上级填 `weapon`，所属细表填 `weapon`。
2. **选属性。** 可以复用一个合适的属性对象；要改变主行或主气，就新增对象键。类别按三元组推导，添加第几千把剑也沿用同一套字典。
3. **建模板与细表。** 在「物品总表」填新的模板键、分类键、属性对象键、来源及整数品阶 ID，再在材料或武器细表填同一模板键。在「物品词条」按阶数登记互不重复的固有词条，各项基点须在本品质的区间内。总表中“项目已有”“系统设计”“玩家创制示例”分别标识来源。
4. **接原型与用料。** 创制示例要有同一细表类型的原型和至少一种材料。每种材料在每个产物下只填一次，可引用先前创制的材料。原型关系和材料依赖各自必须能追溯到起点。
5. **导出并核对。** 执行 `python3 tools/export_affinities.py`，再执行 `python3 tools/export_affinities.py --check`。导出器检查外键、细表覆盖、用量与循环。玩法侧按键查表，新增叶子与模板不需要改已有编号。

## 炼器样例的作品记录

玩家选择器胚、炉火、目标品阶和纳戒里的材料。系统先按炼器师品阶、已装备功法及五行关系估火候。失败结算返材和经验；成功后抽出阴阳、五行、主气和成品词条，分配 `ugc.<ID>`，将成品实例写入纳戒。[炼器规则样例、工艺收益和策划表](smithing-workshop.md)

| 记录 | 存档与查询 |
| --- | --- |
| 玩家模板 | 长期模板 ID 关联作者、名称、分类、器胚、数值规则版本、本炉工艺以及最终词条 |
| 用料快照 | 以材料模板键保存此次实际选材和数量 |
| 库存实例 | 独立的 `GoodsId` 指向作品的 `TemplateId`。转手后同一作品仍可凭模板键查原作者、品阶和词条 |
| 拍卖挂单 | 奇珍阁在售列表支持按完整模板 ID 或作品名查询，成交使用挂牌号 |

自创霜纹铁与霜纹剑用来验证材料和武器的模板关系。丹药同样复用物品总表和造物用料，并通过专用丹方关联地区产出。[炼丹规则草稿](alchemy-design.md)
