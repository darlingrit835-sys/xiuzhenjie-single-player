# 12 虚神界 · 九馆创作

角色达到结丹一阶（21 级）后可从主城进入虚神界。大厅首屏通往虚神殿、虚神塔、虚神祭坛和合道台，四个入口下方是九馆名录。进馆创作需要相应职业职印，作品等阶上限取该职业品阶和修为大境界中较低的一项。一至二品用素墨单轮，三至四品显青玉双轮，五品起显描金重轮。

## 开辟专职内室

从洞府山水图进入「百工坊 → 专职内室」，选择空室、职业并确认开辟。黄阶洞府开放第一内室，玄阶开放第二内室。第一处需 1,000 灵石，再开一处需 10,000 灵石。九职均可选，成功后相应职业从一品起修。已经学过的同类槽位会拦下重复选择。

改建已有内室需 20 灵玉。确认页列出旧内室、将失去的品阶和新专职。放弃某职业最后一枚职印会清除该职业的品阶与研习进度，并登记退职。要重新取得该馆的职印，需要再次开辟或改建内室，从一品起修。公开作品和其他职业存档照常保留。老角色已独立修得的丹、器、符、植工坊品阶也可取得入馆资格。术、阵、道、奇巧、御兽按有效职业槽或已有正式研习档读取品阶。[洞府开辟与改建](../server-go/void_career_learning.go) · [职印与境界](../server-go/void_realm_rules.go)

## 创作、估值与传习

1. 在馆内选择论题和作品等阶。每馆有三道论题和三步专属工序，每步可选三种手法。以丹师的「凝露养脉」为例，文火候两息后直接封炉可得到目标火候 2，并触发省工词条。
2. 选择阴、阳或平和的气性，搭配五行和十二气之一。工序决定能否合题。与论题相应的五行、主气和气性提高契合。三者每与实际材料吻合一项，增加 1 合料分，并按作品等阶提高估值。初试可免费改稿，偏题时会给出具体需要调整的手法。
3. 合题后查看本卷的价值拆解、灵石、悟性与材料实需。估值用于衡量这份谱本。满意后题名确认。服务端按确认报价从角色和纳戒实际扣费，与新作同时存档。八馆可题三至五个汉字，末字按馆内题名规则。符谱沿用所封法术名。同一角色在同馆用同阶、同题和同样工艺、行气组合只可登记一次。
4. 术、阵、道、奇巧、御兽在当前品阶首次署名不同论题时，另计 4 × 品 ×（品＋2）灵石研习费。每品登记齐三道不同论题晋升一品，九品封顶。其他四职沿用各自工坊的修习体系。
5. 在作品详情「附此卷留言」，可写求教、心得或邀试，每则一至一百二十字。道友能公开阅卷，有相应职印、品阶和境界可免费复演。同一账号对每件他人作品只计一次传习回执。
6. 造诣榜取每位作者在所选馆、阶内最高分的作品。传习榜按作品获得的独立回执数排序，两榜同值并列。本人或同账号角色可自验，回执由其他账号留下。

署名交付的是可查阅、可复演的谱本。制作可用物品、学会功法、登记原版专利与兑换奖励，沿用原丹房、炼器等系统。七馆旧版留存作品仍可按当时的法门、收尾和目标刻度复演。奇巧和御兽的作品直接在九馆工作台创作。[九馆工序、论题与相性](../server-go/void_creation_v2.json) · [旧七馆题本](../server-go/void_realm_v1.json)

## 游戏接入与存档

Unity 入口为 `XuShenJieWnd`。游戏 TCP 命令 `4901070` 请求第 3 字段承载 JSON，回包第 1、2、3 字段依次为状态码、成功标识、JSON。身份来自当前角色会话，服务端核验开放境界、职业、工序、资源和回执。[服务端入口](../server-go/void_realm.go) · [报价与扣费](../server-go/void_realm_cost.go)

| action | 输入 | 回包 |
| --- | --- | --- |
| `lobby` | 无 | 角色名、ID、等级、职业槽和九馆开放情况 |
| `enter` | `hallId`、可选作品阶 | 职业品阶与可创作上限 |
| `simulate` | 工序及行气组合 | 结果、目标偏差、改法、词条、估值、成本、持有量及报价编号 |
| `publish` | 同一组合、题名、`quoteId`、`requestId` | 已署名的作品及扣费后的余额 |
| `post` / `board` | 发帖传类别、正文、可选作品及请求编号。读取传类别、页码 | 发帖回执或本页留言 |
| `rankings` | 榜别、可选馆和作品阶、页码 | 作品与名次 |
| `work` / `study` | 作品 ID | 作品，或原谱复演结果与回执状态 |

九馆 ID 对应职业 1–9，依次为 `dan, qi, fu, shu, zhen, dao, qiao, zhi, shou`。新版工序传 `version=2`、`brief=0..2`、`route=1..5`（金木水火土）、`adjust=1..3`（阴、阳、平和）。`steps` 依次为三段工序的 0–2 号手法和主气编号 1–12。造诣榜用 `quality`，传习榜用 `study`，页码从 0 起，每页最多 20 条。

作品和帖子随本服角色存档使用保留的 `$void:` 键，传习回执随作品写入。正式署名核验材料锁定状态、实际持有量与当前报价。作品、扣费、职业修习在一次存档事务内提交。发布和留言用 32 位小写十六进制请求号确认，重试同一请求可取回原单。迁服时备份完整存档目录即可保留作品、留言和回执。

现有客户端工程应先接入洞府山水图、ForgeWire 与基础界面资源，然后在 Unity 工程目录应用虚神界补丁，并配套本仓 Go 服务。洞府学职使用原生 `1005003` / `1005004`，按服务端府籍、槽位和余额结算。原型网页保留初版七馆体验，使用浏览器的示例角色与本地记录。[洞府客户端补丁](../client/patches/cave-residence.patch) · [完整虚神界补丁](../client/patches/void-realm.patch) · [七馆原型](../design/修真界UI/12%20虚神界.html)

## 九馆画面与联机验收

每座工坊使用一件手绘器物和对应的三段操作图。描金星盘播放十六格帧动画，器物在案上浮动，脚下有投影与反光。当前主行改变辉色，十二气各有独立粒子运动。例如风气横掠、雷气折入、寒气结晶、润气下沉、罡气结弧。点选工序会点亮相应的落点，试演与成卷各有光效。九馆实景均从原生 Unity 画面截取。[九馆画面](虚神界九馆实景.jpg) · [十六帧工坊实录](虚神界工坊实录.webp)

Unity 2022.3.62f3 Play Mode 连接独立的本地 Go 服务，两名测试修士从主城进入。青砚先交出偏火草案，修正为文火、两息、直接封炉，定阴性、水行、寒气，署名《归岫清心丹》。作者实际支付 4 灵石、1 悟性与 1 株凝露草，作品得 73 分，估值 57 灵石。估值明细为制谱 4、材料折价 20、悟性折价 2、论题契合 14、合料 3、品评 14。云砚从附卷留言展开原作并免费复演两次，传习榜计 1 人。另一个角色从洞府百工坊以 1,000 灵石开辟奇巧内室，再以 20 灵玉改建为一品御兽师。

九馆共 27 题。服务端枚举了 729 种题目与工序组合，97 种直接合题，其余 632 种按返回的修正建议重演后都能合题。18 种专属词条各自至少可以在一份可署名作品上触发。原生画面另检验了九馆器物、十六格星盘，以及固定相同器物与时间时十二气各自的绘制结果。

## 初版七馆联机验收

Unity 2022.3.62f3 Play Mode 连接独立的本地 Go 服务。青砚从主城进入虚神界，持三品丹师、二品布道师职印。丹师塔首轮试方失败，改用分液合丹后获得 60 分，署名《归岫清心丹》，并发出附卷邀试。重启 Go 服务后，另一账号云砚从留音壁展开原卷、进馆复演并留下回执。回访作品仍为一人传习，作者重新登录也能在传习榜看见同一条记录。原生工作台实际播放了图集的 16 个不同帧。[游戏内四屏与动效](虚神界游戏界面.webp)
