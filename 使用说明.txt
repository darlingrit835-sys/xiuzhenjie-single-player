修真界 · 单机版（本地私服）使用说明
====================================================================

一、这是什么
  原来的包是「客户端 APK + 需要另外一台服务器」的架构。
  这一版把它改成了只在你自己的电脑上跑的离线单机：
    · 服务端跑在你电脑本机（账号服 9443 / 游戏服 17666 / 战斗服 17667）
    · 客户端 APK 的连接地址已改成 127.0.0.1
    · 手机插 USB，通过 adb 反向端口映射把手机的 127.0.0.1 接到电脑上的服务端
  本文件的 USB 步骤适用于本地版 APK（com.LMGame.XiuXianJie），存档默认写入 server\data。
  另行构建的云端直连包可通过网络访问试用服。

二、跑起来（3 步）
  首次安装或重装前，请准备本地版 APK。若已安装，可直接从第 1 步开始。
  将开发证书放入 server\data\server.p12。打开 PowerShell，设置环境变量 XZJ_TLS_PASSWORD 为该证书的口令。
  使用本地版 APK 的完整路径启动：
    $env:XZJ_CLIENT_APK = 'D:\游戏\修真界单机版.apk'
    .\启动游戏.bat
  1. 手机用数据线连电脑，打开「开发者选项 → USB 调试」，手机上点“允许”。
  2. 双击「启动游戏.bat」
     - 默认启动 Go 服务端，等设备、建映射、装客户端、启动游戏
     - 若没有预编译的 Go 服务端，首次构建需要 Go 1.26 或更新版本
     - 第一次装 APK 约 1 分钟
  3. 玩。注意不要关掉那个“修真界服务端”黑窗口，关掉=停服。
  拔插过数据线后，重新双击「启动游戏.bat」即可恢复连接（存档不会丢）。

三、目录说明
  client\修真界单机版.apk    自备本地版客户端的默认放置位置
  server-go\                 默认 Go 服务端
  server\                    共用数据和 Java 回退实现
    server\data\users.json       账号
    server\data\roles.json       角色存档
    server\data\config\server.json   服务端配置（publicIp 等）
  tools\adb\                 用来连手机的 adb
  首次注册和建角会创建账号和角色文件。换机器前先停服，再备份整个 server\data。
  启动游戏.bat               一键启动
  停止服务端.bat             停止本仓库使用默认端口的服务端
  重装客户端.bat             卸了重装 APK

  需要临时使用 Java 时，先停服，然后在同一个 PowerShell 窗口执行
  $env:XZJ_BACKEND = 'java'
  .\start.ps1

四、我改了什么（都可在服务端改回去）
  1. 客户端 DLL 里 Constants.LoginServerIP 由 10.0.2.2 改成 127.0.0.1，
     热更地址同步改为 127.0.0.1:9443，之后重新用原签名证书签过（v1+v2+v3）。
  2. 服务端 Config.PUBLIC_IP 与 data/config/server.json 的 publicIp 都改成 127.0.0.1，
     否则登录后下发的选服地址还是旧的 10.0.2.2。
  3. 修了一个会把人锁死的逻辑：客户端「离开战斗」要求 BattleGuideVal==100
     或新手指引步数≥16，而私服没有完整引导链，导致进了战斗地图就出不来。
     现在服务端登录时直接把战斗引导视为已完成（ServerConfig.completeBattleGuide，
     想恢复原版引导把它改成 false 再重编译）。

五、换机器或改用模拟器
  · 换电脑时复制本仓库，并恢复原来的 server\data 存档目录。
  · 模拟器需要在启动脚本的设备列表中能被 ADB 识别。本地 APK 同样使用端口映射。

六、已知限制
  · 从 Git 历史恢复的本地 APK 仅包含 armeabi-v7a，纯 64 位设备可能无法安装。
  · 本地模式需要电脑上运行服务端。云端试用模式使用单独构建的 APK。
  · 当前玩法支持范围见 docs\interface-pb\go-interfaces.md。
