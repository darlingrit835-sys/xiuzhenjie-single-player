修真界 · 玩家使用说明
====================================================================

一、云端联机测试（Android 1.3.5，版本号 30）

  1. 安装测试渠道发放的 APK。手机需要支持 armeabi-v7a（32 位 ARM）。
  2. 打开游戏，等待安装包内的完整资源完成本地校验和解压。
     后续启动发现较新版本才下载，下载中断后可以继续，同一版本复用缓存。
  3. 联网登录后选择修真界，新账号按界面提示创建角色并进入主城。

  这版使用白鹤青山水墨图标。云端角色进度保存在测试服。
  公网登录、建角、角色登录和战斗连接已验证。Unity Play Mode 已跑到主城，
  Android 真机体验以实际试装为准。

二、本地 USB 单机版（Windows）

  1. 准备完整的本地发行目录。脚本需要下列运行文件。
       client\修真界单机版.apk    本地版 APK
       server\jdk8\bin\java.exe    内置 Java
       server\out\ 和 server\lib\ 服务端编译产物和依赖
       server\data\               配置和存档
       tools\adb\adb.exe          Android 调试工具
  2. 用数据线连接手机，开启 USB 调试并在手机上允许这台电脑。
  3. 双击「启动游戏.bat」。脚本启动本地服务，配置 9443、17666、17667
     三个端口的 USB 转发，再安装并打开客户端。
  4. 结束游戏后双击「停止服务端.bat」。拔插数据线后重跑启动脚本即可恢复转发。

  账号和角色记录位于 server\data\users.json、server\data\roles.json。
  停服后可以备份整个 server\data\。换电脑时随完整发行目录一并复制。
  遇到端口或服务启动问题，先看 server\data\console.log 和 console.err.log。
  「重装客户端.bat」会卸载手机上的单机客户端，再安装本地版 APK。

三、选择正确的测试包

  云端测试包从手机联网访问测试服。本地启动脚本使用固定路径读取单机 APK。
  从 Git 克隆适合阅读和修改源码。需要安装时，请获取对应的测试 APK 或完整发行目录。

四、开发者入口

  仓库 README.md 提供目录索引。
  UnityProject\README.md 说明 Unity 版本、资源位置和本地构建入口。
  docs\联机测试与热更新.md 说明云端使用方式和签名发布流程。
  docs\单机化改造.md 记录旧单机包的改址、端口和战斗退出修复。
